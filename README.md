# StudentPorfolio – Online Portfolio Template Generator

## Project Description
StudentPorfolio is a web-based application that allows users to create, generate, preview, and manage their own portfolios using three different templates: Simple, Modern, and Creative. It stores portfolio information in an online database and allows users to view, edit, and delete their saved portfolios.

## Technologies Used
- Laravel
- PHP
- Blade
- HTML
- CSS
- JavaScript
- PostgreSQL
- Supabase
- Railway
- GitHub

## Main Features
- Create and save portfolio information.
- Upload a profile picture.
- Select one of three portfolio templates.
- Generate and preview portfolios.
- Manage multiple saved portfolios.
- Edit and delete portfolio records.
- Store information in an online database.

## Portfolio Templates
1. **Simple** – Clean and professional design.
2. **Modern** – Modern layout with cards and visual elements.
3. **Creative** – Creative and distinctive professional design.

## Database Information
- **Database Platform:** Supabase
- **Database Type:** PostgreSQL
- **Database Table:** `portfolios`

The database stores personal information, education, skills, projects, work experience, social links, and the selected portfolio template.

## Database Structure
The `portfolios` table includes fields such as:
- `id`
- `full_name`
- `profile_picture`
- `email`
- `contact_number`
- `address`
- `about_me`
- `education`
- `skills`
- `projects`
- `work_experience`
- `social_links`
- `selected_template`
- `created_at`
- `updated_at`

Verify these field names against your actual database.
